# Fictional Student Dataset

**Course:** CUL-CYB 371 – Data Mining and Data Warehousing

## Description
This project contains a fictional dataset of 20 students. It includes:
- Student ID
- Department
- Level
- Attendance Percentage
- Average Examination Score

All student records are fictional and created for academic purposes.

## Files
- `generate_dataset.py` – Python program used to create the dataset.
- `students.csv` – Dataset saved in CSV format.

## How to run
1. Install Python 3 if it is not already installed.
2. Open a terminal in this project folder.
3. Run:

```bash
python generate_dataset.py
```

The program creates `students.csv`.
